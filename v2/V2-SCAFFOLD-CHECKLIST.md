## □ 标准 6：编辑工作流定稿

### 验收要求
- [ ] 编辑招聘完成（Week 4-6）
- [ ] 内容生产流程：
  - [ ] 主编：定主题 / 排期 / 审稿 / 发稿
  - [ ] 编辑：写 / 改 / 配图
  - [ ] AI：起草初稿 + 数据查询
- [ ] 内容质量标准：
  - [ ] AI 起草 100% → 编辑改写 ≥ 70%
  - [ ] 单审（主编一审即发）
- [ ] 发布频率：
  - [ ] 触发式（B2 / B5 / S3 事件触发 → 24-48 小时内发）
  - [ ] 每周汇总（B1 / B3 每周 2-3 篇）
- [ ] 工具就绪：
  - [ ] 编辑看板（Notion / 飞书 / 自建）
  - [ ] 审稿流程（GitHub PR / 飞书审批）
  - [ ] 排期表
  - [ ] 数据查询接口（IECG / 选校帝 / US News）
- [ ] 主编试用通过

### 验证方式
- 主编跑一次完整流程（选题 → 写作 → 审稿 → 发布）
- 时间预算：每周 8-10 小时（选题 2h + 审稿 4h + 排期 2h + 沟通 2h）
